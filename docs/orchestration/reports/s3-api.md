- What was built:
  - `mpa/api/app.py`: `create_app(run_fn=None, deps=None, *, keepalive_s=10)` and module-level `app`. `GET /health` (`status, version, llm_mode, data_source, tracing`; never touches LLM or data; shows `unknown` if settings are invalid). `POST /briefings` (SSE). `GET /sources/{type}/{id}` (404 `not_found`, 422 on bad type or id pattern, 503 on `DataSourceError`/`NotImplementedError`). CORS for `http://localhost:3000` and `http://127.0.0.1:3000` only (GET, POST, OPTIONS). Pure-ASGI request log (method, path, status, ms; never bodies, query or env). Validation errors return `{"error":"validation_error","detail":[{loc,msg,type}]}` without echoing input.
  - `mpa/api/sse.py`: `: stream-open` first, `: keep-alive` every 10 s, one `event: <type>` + compact one-line `data:` per event, every event re-validated through `AgentEvent` and size-checked (≤ 8 KB) before it is framed, stream ends after `run_done` (anything after it is dropped). Run executes in a producer task behind a bounded queue; client disconnect cancels the producer, the `run_fn` generator and its child tasks. Any `run_fn` exception, invalid or oversize event, or a stream that ends without `run_done` becomes a safe terminal sequence built with the contract models: `subagent_failed` (reason `error`, text `internal error`) for agents still open, then, if a `plan` was seen, a `verifier_result` with zero counts when none was sent and empty `draft`s for the sections not yet drafted (last one `complete=true`), then `run_done` with `partial=true`. The result passes `check_event_order` and `assemble_pack`. No exception text, traceback, URL or env value is ever sent; only the exception class name is logged. The tracer is flushed in the background after each run.
  - `mpa/api/deps.py`: lazy, thread-safe `DepsProvider` (settings, data source, run deps built on first use; `/sources` needs only the data source). Default `run_fn` is `mpa.agents.orchestrator.run_briefing`, imported at the first request. Any missing module or failing builder gives `503 {"error":"service_unavailable"}` for that route only.
  - `mpa/tracing/`: `build_tracer(settings)` (`off` → `NoopTracer`; `langfuse` → `LangfuseTracer`; falls back to `NoopTracer` with exactly one warning that names only the reason: `keys_missing`, `host_missing`, `package_missing`, `unreachable` (2 s health probe), `init_failed (<ExceptionClass>)`). `LangfuseTracer` (Langfuse Python SDK 2.x): one trace per run id, nested spans, `llm` spans as generations, `record_llm` generations with model, input/output, usage, cost and latency.
