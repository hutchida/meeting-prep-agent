- Known gaps / follow-ups:
  - **Recordings**: none committed. Replay keys cover the system prompt, tool results and the `verifier`/`writer` prompts, so any change to prompts or to the data invalidates recordings; the master should record last, after the final merge. A miss never crashes: the agent fails with `error`, the briefing is partial and the stream stays valid (tested).
  - Model variance: with the same prompts two live runs differ in which emails the correspondence agent reads, so fact-source coverage varied between 6 and 8 of 8 on Kettle & Crumb and 7 and 8 on Halden Pay (missed items were D9 chargeback rate, C27 Crumb Club, E44/C24 margin model in single runs). S4's evals will measure this; recording a good run is the stable answer for the demo.
  - The verifier is conservative: sentences that synthesise across sources ("there is a contradiction ...") or add inferred dates are sometimes dropped as `unsupported` (3-4 sentences per run); the `meeting_at_a_glance` first sentence is built from the calendar item itself so it always survives. The deterministic check is unit-tested against the planted facts in `data/PLOT.md`: all 24 pass, and changing a figure fails each of the 23 that contain one.
  - Meeting resolution is rule-based (client aliases from calendar titles, weekday names, next 14 days from `demo_now`). `today`/`tomorrow`/`next week` are not interpreted; ambiguous or unknown requests give a partial briefing that lists the candidate meetings (placeholder `meeting_id` `M0`, title "Meeting not identified", because the contract requires those fields).
  - `FaultInjectingDataSource` wraps the data seen by the sub-agents only; meeting resolution and the Verifier read the unwrapped source (so `FAIL_SOURCE=all` still produces a briefing header). If the API wraps the data source itself before calling `run_briefing`, resolution can fail and the briefing says the calendar could not be reached.
  - `Stats.steps` counts LLM calls (agents, writer, verifier check), not tool calls.
  - Contract observations (no change made): `PlanEvent.meeting_title/meeting_start` are optional in the schema but required by `assemble_pack` (as noted in g0c); budget `time` is in the `budget_hit` enum but never emitted (timeouts are `subagent_failed(timeout)`).
